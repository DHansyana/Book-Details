# Book-Details

## Book Information
- Book ID : BookID
- Name of the book : Title
- Name of the author : Author
- Published Year of the book : Year 

## Project Description
- This project was developed using Java and IntelliJ IDEA.

## Features
- Add books
- Delete books
- Search books
- Sort books
- Replace books
- Show all details of book list

## Technologies Used
- Java
- IntelliJ IDEA
- GitHub
- SonarQube
